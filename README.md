# Pruebas unitarias con JavaScript y GitHub Actions

## Objetivo

Probar individualmente una función que calcula el importe de un platillo a partir del precio y la cantidad. Automatizar su ejecución mediante GitHub Actions.

## Requisitos

- Node.js 22 o versión compatible con `node:test`.
- Visual Studio Code.
- Cuenta de GitHub para la automatización.


## Ejecución local

1. Clonar el repositorio de GitHub a tu equipo de Computo.
2. Después de clonar Abrir la carpeta en VS Code.
3. Abrir la terminal.
4. Verificar `node --version`.
5. Ejecutar `npm test` (en PowerShell, si `npm` está bloqueado, usar `npm.cmd test`).
6. Verificar **5 tests, 5 pass, 0 fail**.
7. La Prueba Unitaria fue Exitosa.
